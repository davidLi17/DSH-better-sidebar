## Changes

The agent loop now owns model routing and the durable projection. Live routes use `agent.model.current()` and `agent.model.select()`; an unchanged choice is a no-op and an omitted effort is not inherited. `installModelSelection(ctx)` only installs a switch notice and belongs in unpublished creation/resume setup. The plugin no longer keeps a second mutable model ref or appends the selection twice.

Development pins and DSH peers move to 0.2.2-rc.1. Cordis 4.1.0, group/include 1.1.0 and schemastery 3.19.0 follow the official tuple. PTC event types moved to `dsh-tool-executor-ptc/types`; only the test's type import changes. Standalone installers and CI use the same exact host. No workflow permission changes, tags, npm publication or installation-package uploads.

Selected-text draft handoff, image admission, sidechat history, watermark rebasing, file save/preview behavior and existing client services remain intact. The GBK and dock-anchor fixes are narrowly backported with upstream regressions.
